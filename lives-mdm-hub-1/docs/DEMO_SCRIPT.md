# Demo video script (about 2 minutes 45 seconds)

The brief asks for a 2-to-3-minute screen recording. The voiceover below is about 420 words, which is about 2:45 at a calm pace. Every click is on the home page's **Try the demo** list, so the video follows the same path a judge can repeat.

## Before you record

- Use Chrome or Edge at 100% zoom, window about 1440 × 900, light mode, bookmarks bar hidden.
- Open the live prototype and click **Reset demo** (bottom of the left rail) so the clock reads **Thu 1 Oct, 09:00**.
- Record with any screen recorder (OBS, QuickTime, the Windows Game Bar or Loom). Record the voiceover in one take per section; you can trim between sections.
- Upload to YouTube as **Unlisted** (not Private, or judges cannot open it), then paste the link into the summary and the README.
