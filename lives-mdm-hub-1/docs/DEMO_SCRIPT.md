# Demo video script (about 2 minutes 55 seconds)

The brief asks for a 2-to-3-minute screen recording. The voiceover below is about 400 words: 2:45 at 150 words a minute, 2:55 if you speak a little slower, so there is room to breathe. Every click is in the left rail, the top bar or the page itself, the way someone at Lives Group would use it.

## Before you record

- Chrome or Edge at 100% zoom, window about 1440 × 900, light mode, bookmarks bar hidden, notifications off.
- Open the live GitHub Pages link (or run `python3 server.py` in the project folder and open `localhost:8000`).
- Reset the demo: on the login page click **Priya**, then **Sign in**; click **Reset demo** at the bottom of the left rail, then **Yes, reset**, so the clock reads **Thu 1 Oct, 09:00**. Click **Log out**. You are back on the login page: start recording here.
- Record the screen first, without talking, following the *On screen* column. Stay on each screen 2 to 3 seconds longer than feels natural; the editor can cut extra time but cannot add it.
- Then play the recording back and read the *Say* column over it, one take for the whole video. Start the voice recording, wait two seconds, then press the space bar to start playback: the key click marks where the video starts.
- Sign-ins: the first one (Amy) stays on screen so viewers see the login page. For each person after that, click **Log out** (top right), click their card under *Demo accounts* and **Sign in**; the editor can cut each of these to about a second while the voiceover carries on.
- Send the editor the screen recording, the voice recording and this script.

## If it runs over 3:00

Cut in this order until it fits:

1. Skip opening **Request tracker** at the end of the Wei Jie shot (about 4 seconds).
2. Skip the **SAP import file** tab in the Priya shot (about 4 seconds).
3. In the regional view, show only the table and the forecast comparison, and drop the sentence about switching to the records in SAP today (about 8 seconds).
4. Drop the market scenarios shot (about 17 seconds).
